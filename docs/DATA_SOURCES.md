# Public fixture provenance

Phase 0 vendors the official public PS1 input package and the published Scenario-A sample answer key under `data/public-instance/`.

- Source: <https://github.com/aochinwen/NebulaX-Hackathon-ProblemStatement/tree/main/PS1>
- Inputs: `PS1/01_data/`
- Sample: `PS1/03_submission_sample/`

`manifest.json` records the source revision, retrieval timestamp, and SHA-256 checksum for each vendored CSV. These fixtures are for schema/export regression only; they do not establish feasibility without the organiser validator.
